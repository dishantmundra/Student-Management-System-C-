
# Student Management System — C++

## Project Description
The Student Management System is a simple console-based application developed using C++. It allows users to manage student records by adding, displaying, searching, and deleting student information.

## Features
- Add a new student
- Display all student records
- Search for a student using roll number
- Delete a student record
- Prevent duplicate roll numbers
- Simple menu-driven interface

## Information Stored
- Roll Number
- Student Name
- Marks

## Technologies Used
- Programming Language: C++
- Standard C++ Library

## Concepts Used
- Structures
- Variables and data types
- Functions
- Vectors
- Loops
- Conditional statements
- Switch statement
- User input and output

## How to Run

1. Install a C++ compiler, such as GCC.
2. Save the program as `main.cpp`.
3. Open a terminal in the folder containing the file.
4. Compile the program:

   g++ main.cpp -o student_management

5. Run the program:

   Windows:
   student_management.exe

   Linux/macOS:
   ./student_management

## Project Purpose
This project was created to practise basic C++ programming and understand how student records can be managed through a menu-driven application.
